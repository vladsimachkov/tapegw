# Спайки M0

Здесь лежат выводы спайков этапа M0. Формат — по одному файлу на вопрос из чек-листа M0
в `docs/ARCHITECTURE.md`, имя `M0-<NN>-<короткое-имя>.md`.

Код спайков в основную ветку **не попадает** — только выводы и, если нужно, ссылки на
ветки. Каждый файл отвечает на три вопроса:

1. Что проверяли и на какой версии (тег Phobos, версия versitygw, стенд).
2. Что получилось — конкретно, с выводом команды или фрагментом кода.
3. На что это влияет: значение настройки в `config`, пункт плана, ограничение в коде.
